# Install Flight Control 2 preview

1. Install FotG 2.0.2 with its SDL3 engine and MyMod template. Run it once, create a pilot, and exit.
2. Extract the entire player ZIP. Close Hangar Bay and WheelBridge if upgrading.
3. Run Setup.exe and point it to the folder containing Knossos.NET.exe and kn_portable. Click Install / Repair.
4. Open Hangar Bay.exe beside Knossos. On Deploy, select the base game or an installed compatible mission pack, then choose Standard Flight.
5. Use Console for Flight Response, Wheels, Buttons and Profiles. Close the game before applying changes.

Setup stages the overlay in MyMod and stores overwritten files under Flight Control Backups in the game folder and changed pilot controls under FreeSpaceOpen/ControllerSetupBackups. An existing Flight Control wheel config and generated control table are retained on repair. For a new pilot, use Buttons → Reserve wheel buttons before flying.

Use Advanced (Experimental) for custom bindings, axes and gestures. Flight Control recommends configuring the gamepad in its console. Profile exports cover console settings and omit game-native controls and campaign progress.

FotG 1.1.3 remains available through the Classic install path. Keep your existing 1.1.5 package for the established Classic release. The FotG 2 preview currently targets 2.0.2 specifically.

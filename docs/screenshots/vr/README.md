# VR gameplay examples

These are pixel-exact crops of the square Fate of the Galaxy game window while
Flight Control's OpenXR VR launcher was running on 2026-11-08. The source
desktop captures were 1920×1200; the game-only crops are 1000×1000 PNGs.
The three wheel details are further 600×400 crops of those PNGs. No game
pixels were redrawn, enhanced, or generated. The desktop, ChatGPT window,
Windows title bar, and taskbar were excluded.

These show the desktop VR mirror, **not** a stereoscopic headset photograph.
Use the term *VR preview* until the matching build has been released. Show
the project's unofficial fan-tool disclaimer with the gallery.

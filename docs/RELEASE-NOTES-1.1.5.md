# Flight Control 1.1.5 — final 1.x build

This build supports Fate of the Galaxy 1.1.0–1.1.3 on Windows. Fate of the Galaxy 2.x changes the engine and input bindings and is outside this build's compatibility range.

## Changes since 1.1.4

- Added direct Manual Power and Shield Allocation editors to the Systems wheel. The former selects Lasers, Engines, or Shields and adjusts the game's native ETS values. The latter redistributes front/rear or four-section shields without creating energy.
- Added the targeting computer toggle and next-subsystem action to the Targeting wheel.
- Added quick and held actions for weapon banks, ship modes, gun linking, torpedo linking, and mouse control needed in the Excoriator training mission.
- Added the tutorial's key events for shield redistribution and ETS adjustments while retaining the wheel's selected values.
- Updated the built-in help. The Excoriator tutorial was completed in the local 1.1.3 game with this build.

Other campaigns and multiplayer have not been verified with these additions. The game, engine, and this tool are separate downloads.

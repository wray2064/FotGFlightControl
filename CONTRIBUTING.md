# Contributing

Bug reports and controller compatibility findings are welcome. Include the
game and engine version, Windows version, controller model, ship and mission,
and steps to reproduce. State whether you launched through **Play with Gamepad
Wheel.exe**. Do not post pilot files, private logs or personal paths publicly.

For code changes, keep the add-on independent of the base game files. Test the
build with `Package.ps1` and describe any real-controller flight or menu tests
you ran. Update the help and screenshots when changing visible controls.

Please do not submit game assets, engine binaries, music, copied stock tables,
or other third-party files. The repository's MIT license covers the original
add-on code and materials here; it does not cover the game or its engine.

Contact dev@manictrashpanda.dev for contribution questions.

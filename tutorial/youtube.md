WHAT YOU WILL LEARN
- Switching Controls to Advanced to unlock the HOTAS tab
- Scanning several devices at once, including two identical ones
- Press-to-assign for buttons, axes, hats and encoders
- Game actions versus Flight Control actions (wheels, gamepad features)
- Using one button for different jobs while a wheel is open
- Stepping through a wheel with a rotary encoder
- Game and Precision axis modes, calibration and dead zones
- Apply, Restore backup and Gamepad mode
- Saving and sharing .fchotas profiles safely

GOOD TO KNOW
Precision flight axes (per-axis dead zone, curve and calibration), game actions on a hat, axes used as buttons and encoders are still experimental. Check each one in the game. Close the game before pressing Apply, then start it from the Flight Control launcher.

FATE OF THE GALAXY / FLIGHT CONTROL

Hangar Bay & Flight Control Help

Flight Control 2 preview supports FotG 2.0.2 with its SDL3 engine and retains the Classic installer for FotG 1.1.0–1.1.3. This independent addon uses a Lua HUD script, an XInput bridge and an external configuration console.

Set up

  1. Install a supported Fate of the Galaxy release and run the unmodified game once to create a native pilot. Exit the game.
  2. Extract the ZIP; close any older controller companion.
  3. Double-click Setup.exe. If needed, browse to the game folder containing Knossos.NET.exe and kn_portable, then click Install / Repair. Setup checks the version and pilot before changing files.
  4. Open Hangar Bay.exe in the game folder. Choose the base game or an installed mission pack, then launch Standard Flight or OpenXR Flight for VR. Keep the bridge running in the tray.
  5. Open Console in Hangar Bay to change flight response, button actions and command wheel macros. Close the game before saving; restart it to load changes.

The installer backs up native v4 pilots before reserving A, B, X, Y, LB, RB, Start, L3, R3 and D-pad joystick inputs for the wheel. RT takes over primary fire in flight. If you create a new pilot later, reserve those controls in the console.

Close the game before applying settings, repairing, restoring, or removing the tool. Restart the game after changing the controller or saving wheel settings.

FotG 2 and MyMod

Setup installs Flight Control into MyMod and places Hangar Bay.exe beside Knossos. Launch from Hangar Bay so WheelBridge starts with the game. To play a compatible mission pack, select it on Deploy. The load order is MyMod, the selected pack, then FotG 2.

Console modes and profiles

Default keeps the recommended editing view. Advanced (Experimental) unlocks button actions, gesture settings, wheel layouts and custom flight axes. Configure the gamepad in Flight Control for consistent behavior. Advanced behavior depends on the installed game and controller.

Profiles exports the current console mode, buttons, axes, wheel layouts, macros, timing, display and flight-response settings. Import loads them for review. Save Wheel and Apply with Backup commit the two sets of changes. Game-native bindings and save progress remain in the pilot backup.

Switch controller

Close the game, open Hangar Bay Service > Choose controller, and choose the XInput slot whose preview moves with the controller you want. Press Apply with backup. Flight Control matches the slot to the game engine's SDL joystick and saves both selections; restart the game. If SDL cannot match it automatically, select the same physical controller from the device list. A saved controller that is disconnected will not silently fall back to another pad.

In flight

ButtonPanel
D-pad downSquad commands from the live native communications menu
D-pad upShip systems: energy, shields and speed
D-pad leftTargeting: choose the ships X cycles, select subsystems or turrets, return to hull, toggle the targeting computer, or clear target; up-left cycles subsystems on the current target without aiming at them
D-pad rightFour macros on cardinal slots; mission commands on diagonals

Tap a D-pad direction for its wheel. Hold it past the configured delay to look up, rear, left or right; release to center the view. The Macro Deck slider sets 150–600 ms (250 ms by default). Disable look around to make every D-pad press open its wheel immediately. Menus keep immediate D-pad navigation. Save Wheel and restart after changing this setting.

RT fires primary weapons and LT fires secondary weapons in flight while no wheel is open. Hold LT for repeat secondary fire where the weapon supports it. Tap LB cycles secondary banks for LT; hold LB links torpedo banks (Q). Hold Y to fire the B-wing or T-Blade bomber third gun directly; Y has no flight action on other ships. Hold RB to change the available ship mode: Falcon gun control, TIE burst fire, S-foils, or targeting computer. A targets the ship in the reticle, B targets the closest ship attacking you, and X cycles the selected target class when no wheel is open. B cancels an open wheel; the targeting wheel also offers Clear target, Target subsystem / Target hull, Next live turret, Next subsystem and Toggle targeting computer (Z). Tap Start to pause; hold it to cycle Cockpit, Chase and External cameras. Tap L3 matches target speed; hold L3 links guns (E). Tap R3 cycles subsystems on the targeted ship; hold R3 toggles mouse movement (N). Stick clicks have no flight action while a wheel is open.

Manual Power: tap D-pad Up for Systems, then press Y for the three-arc view. Flick either stick up/down to select Lasers, Engines, or Shields; left/right previews an immediate change. X gives all 12 points to the selected system. A applies and closes; B or Y cancels. In Excoriator training, applying also sends the selected system's required increase/decrease key pair before restoring the preview. The three ETS values share 12 points; multiplayer power editing is unavailable.

Shield Allocation: from Systems press X. Two-section ships show Front/Rear; four-section ships show Front/Right/Rear/Left. Up/down selects a section, left/right transfers existing shield strength, and X fills the selected section up to 200% of its balanced value. A applies and closes; B or Y cancels. Applying Front in Excoriator training also sends Alt+W for its objective.

Center both sticks, point either stick toward a segment, then press A. B cancels. Tap the same D-pad direction to close a panel. Commands with more than eight entries have page segments. Depart or warp orders need a second A press.

Menu / Start: tap to pause; hold for 500 ms to cycle Cockpit, Chase and External camera views. The Macro Deck checkbox disables this hold action. The Buttons tab in Advanced mode sets the quick-press action of A, B, X, Y, LB, RB, L3 and R3 and, with long presses on, a long-press action for all but Y. Actions marked while held (afterburner, third gun) repeat as long as the button is down. A and B still confirm and cancel inside an open wheel. In Assault missions, the squad command wheel also offers Cycle boarding party task, the same action as keyboard 4.

In menus

D-pad moves through the seven main-menu choices directly. On other menus it sends arrow keys; A activates the keyboard selection. Move either stick to steer the pointer on screens with custom controls, then A or RT clicks. B goes back, LB/RB move between tabs, Start and X send Enter, and Y sends Backspace. Pointer fallback uses only the gamepad; a touchpad or finger mouse is not required. Some mission-specific screens may still need stick pointer control.

Macros

The Macro Deck has four configurable cardinal slots. D-pad Right diagonals open Responses 1–5 (up-left), Responses 6–0 (up-right), Dock / nav (down-left), and Other mission (down-right). Select a group with A, then a command with A; B returns to the macros. Numbered prompts send real number keys. Dock / confirm sends Enter, which depends on the mission. Other mission offers F4 log, F11 fleet info and Space fleet page. Hold LB + RB together to request hyperspace; the game still decides whether a jump is allowed. Available actions are maximum shield energy, nearest enemy, enemy subsystem, match target speed, balanced energy and boarding party task cycling during Assault missions. For enemy subsystem, choose engines, weapons, shields, navigation, turrets or sensors. The addon checks whether the target and subsystem are legal before changing the target. Macro labels are display text, not executable scripts.

Game updates and the version override

If the game is updated to a version this build does not list, Setup shows Unsupported game version and offers Override version check. Ticking it installs for that version anyway, after a warning: compatibility cannot be guaranteed while the override is in use, until Flight Control is updated for that version. Setup still checks the game's control defaults first and changes nothing if they are in a layout it does not recognise. Report how it went at dev@manictrashpanda.dev.

Restore

The Hangar Bay Console stores timestamped copies under kn_portable/HardLightProductions/FreeSpaceOpen/ControllerSetupBackups. Select a pilot and press Restore latest backup to restore its full pilot JSON and FotG settings INI. Macro configuration also gets a backup before each save. Hangar Bay Service lists backups. For FotG 2, rerun the extracted Setup.exe to repair. Restore the desired pilot controls before removal. Hangar Bay can't delete its own file while it is open, so it then shows Hangar Bay.exe in File Explorer; delete it after Hangar Bay closes to finish.

Flight axis layout

The default Classic direct (tested) layout uses the engine gamepad axes: right stick steers in yaw and pitch, left stick rolls and adjusts relative throttle. Choose Classic inverted pitch to reverse the right stick's vertical direction. The 1.1 game default instead steers on the left stick and has no throttle axis. In the console, Flight Axes can be switched to Game's saved setup. Save Wheel and restart the game. For the closest v1 response, set sensitivity to 5 and deadzone to 10% on Flight Response, then Apply with Backup. The classic preset is generated locally from the installed 1.1 control table; the base table is not edited. It reserves A, B, X, L3, R3, LB, RB, Y and Start for context-aware controller actions. Recheck any custom button bindings after switching.

Hyperspace shortcut

In flight, press LB + RB together (within 120 ms), then hold both for 300 ms to request hyperspace using Return, the game's default Engage Hyperdrive binding. Release both before trying again. Steering and trigger fire remain available. The game still decides whether a jump is allowed. The shortcut is inactive in menus and command wheels. Individual shoulder presses retain their configured actions, with a 120 ms decision delay; this also delays the start of custom held actions. If you release an unfinished combination, neither shoulder action runs. If you rebind Engage Hyperdrive away from Return in the game, this shortcut must be updated to match.

Custom flight axes

In the Hangar Bay Console, choose Custom axes under Flight Axes and press Edit axes... to pick the stick axis for yaw, pitch, roll and throttle, each with an invert option. Save Wheel and restart the game. Install / Repair keeps your custom axes. Game's saved setup leaves the axes to the game's own Controls menu instead.

Updates

Setup and the Hangar Bay Console check manictrashpanda.dev for a newer Flight Control when they open. Setup then shows Update to x.y.z; it downloads the release from the product site or GitHub, checks its SHA-256, and shows the new Setup.exe in File Explorer; close Setup and run that one. Turn this off with Check for updates in Setup. Windows may warn about an unknown publisher because the builds are not code-signed yet.

Wheel readability

Wheel labels use dark backplates and bright text to stay visible against laser fire and explosions. In the Hangar Bay Console, open the Wheels tab and set Wheel Text to Medium (20 px) or Large (30 px), with Bold on or off. Save Wheel, then restart the game. Medium Bold is the default. Large text may take more screen space at low resolutions.

Limits

The command wheel uses the game's native order list; it cannot force a mission-disallowed order. Single-player restrictions apply to energy and subsystem macros. Flight Control has been tested extensively in practice missions on a Legion Go 2, ROG Ally X, Xbox controllers and generic gamepads. The campaign and multiplayer have not yet been tested.
